# YourHR — React Frontend

Frontend application for the YourHR platform, built with React and Vite.

## Overview
This repository contains the client-side application. Components, routes, state management, and form handling are defined by the source code.

## Related Project
- [YourHR Spring Boot Backend](https://github.com/MahiTzy/YourHR-server-springboot)

## Technology
- React
- Vite
- JavaScript
- CSS
- Node.js and npm

## Prerequisites
- Node.js (LTS recommended)
- npm
- YourHR backend available for API-driven workflows

## Getting Started
```bash
git clone https://github.com/MahiTzy/YourHR-UI-react.git
cd YourHR-UI-react
npm install
npm run dev
```
Open the local URL printed by Vite.

## Configuration
Review the API service and environment configuration for the backend base URL. Do not put private credentials or secrets in browser-exposed variables.

## Build
```bash
npm run build
``
Use the preview script in `package.json` to inspect the production build.

## Development
Run the backend and frontend together to validate integrated workflows. Use browser developer tools to troubleshoot client-side and API errors.
